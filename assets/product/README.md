## 実物写真から分かったこと（2026-09-08 追記）
- **ボトルは白のマット樹脂、角丸の直方体、肩がなだらか**。ポンプは白の標準的なディスペンサー。全高：幅 ≈ **2.26 : 1**、本体のみ 高さ：幅 ≈ **1.58 : 1**、ポンプ部が全高の約 30%。
- **ラベルは白い紙質で、ボトルの白よりわずかに温かい**。枠線は細く、実物では目立たない。
- **イラストのピンクは実物の方が濃くて赤い**（実測 `#C2657C` 付近、彩度 0.48。レンダーは 0.25）。「ChenMe」の文字も暖色光下ではローズ寄り（`#C26B7F`）に見える。商品名の青は実物では**青みグレー**（`#898A92` 付近）で淡い。
- したがって **グレーディングでラベルを紫に寄せない・彩度を下げない**。実物の「ピンクが少し濃い」状態が正。
- 切り抜き解像度は 474×1056。**縦 1920 のフレームで全高 50% までなら等倍以下で置ける**。ポンプのマクロ（A#5・B#3）には足りないので、**マクロは実写必須**。

## 絶対ルール
1. **ラベル・イラスト・ロゴ・ボトル形状を改変しない。** 変形（縦横比変更、ワープ、パース補正）、色変更、トリミングによる要素の欠落、文字の打ち直しはすべて禁止。
2. **拡縮は縦横比ロックの等倍スケールのみ。** 回転は実際にボトルを置いた状態で起き得る範囲（±15°程度の傾き）まで。
3. **明るさ合わせは「露出（明度）の全体調整」のみ許可。** 色相・彩度は触らない。ラベル領域はマスクして保護する（`05_production/bottle_placement_workflow.md` 参照）。
4. **AI生成にボトルを"描かせない"。** 生成AIには背景・人物・手元だけを作らせ、ボトルはこの正式画像を合成で置く。または実物ボトルを実写する。
5. 切り抜き PNG は `rembg`（isnet-general-use）→ 最大連結成分のみ保持 → 回転で水平化、の手順で作成。再生成は `05_production/bottle_placement_workflow.md` §2.1。
6. 正式画像が後日追加・差し替えされた場合は、このREADMEの表を更新し、全成果物の参照先を差し替える。
