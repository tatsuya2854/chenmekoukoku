## 絶対ルール
1. **ラベル・イラスト・ロゴ・ボトル形状を改変しない。** 変形（縦横比変更、ワープ、パース補正）、色変更、トリミングによる要素の欠落、文字の打ち直しはすべて禁止。
2. **拡縮は縦横比ロックの等倍スケールのみ。** 回転は実際にボトルを置いた状態で起き得る範囲（±15°程度の傾き）まで。
3. **明るさ合わせは「露出（明度）の全体調整」のみ許可。** 色相・彩度は触らない。ラベル領域はマスクして保護する（`05_production/bottle_placement_workflow.md` 参照）。
4. **AI生成にボトルを"描かせない"。** 生成AIには背景・人物・手元だけを作らせ、ボトルはこの正式画像を合成で置く。または実物ボトルを実写する。
5. 正式画像が後日追加・差し替えされた場合は、このREADMEの表を更新し、全成果物の参照先を差し替える。
