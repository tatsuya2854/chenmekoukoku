## 0. 3行で
- ChenMe は「**今日より明日。もっとスッキリ。**」を約束する、**夜の3分を自分に返す**ためのブランド。
- 見た目は **韓国コスメの洗練 × 等身大の可愛さ**。ピンクだけど甘すぎない、白の余白で締める。
- 言うのは **気分・習慣・ご褒美**。言わないのは **効能の断定・身体の変化・比較・煽り**。

## 1. ブランドの世界観

### 1.1 ブランドの核（Brand Core）
| 項目 | 内容 |
|---|---|
| Purpose | 頑張った脚に、1日の終わりの「おつかれ」を言う時間をつくる |
| Promise | 今日より明日。もっとスッキリ。（※気分・印象の話。身体変化は約束しない） |
| Personality | やさしい／ちょっと大人／自分のことをちゃんと好き／ゆるいけど手抜きじゃない |
| Ritual（儀式） | 「靴を脱ぐ → ポンプ1回 → ほぐほぐ → 明かりを落とす」 |
| Enemy（敵） | 我慢、後回し、「自分のケアは最後」という癖 |

### 1.2 ペルソナ（誰に向けて話すか）
**メイン：18〜26歳。学生〜社会人3年目。** 立ち仕事・通学・ヒール・推し活の遠征で脚がパンパン。韓国コスメ好き、SNSで「夜のルーティン」系を保存する。安っぽいのは嫌。でも高級すぎると距離を感じる。
**サブ：27〜34歳。** 仕事終わりの自分時間を大事にしたい。「若い子向け」に見えたら引く。だから**幼く見せない**。

> 一文で：「頑張ってる自分を、ちょっと甘やかしたい夜の女の子（と、その少し先を歩く人）」

### 1.3 ムードキーワード
`夜のピンク` `ベッドサイドの灯り` `ハーブティー` `サテンの光沢` `手描きのゆるさ` `静かなASMR` `ため息のあとの笑顔`

### 1.4 世界観の"軸"（ここを外すとChenMeじゃなくなる）
- **時間帯は夜〜寝る前**（朝・昼のシーンは「伏線」としてのみ）
- **場所は自分の部屋**（ジム・サロン・オフィスは「ビフォー」の描写まで）
- **1人の時間**。友達と一緒なら"会話の中でふと出る"程度
- **光は暖色の低照度**。蛍光灯・白飛び・青白い光は禁止

## 2. トーン＆マナー

### 2.1 声の設計（Voice）
| 軸 | ChenMe の位置 | NG側 |
|---|---|---|
| 距離感 | 仲のいい先輩／少し先を歩く友達 | 先生、メーカー、店員 |
| テンション | 静かに嬉しい。「ふう」と「ふふ」 | 「！！！」連発、叫ぶ、煽る |
| 語尾 | 「〜しよ」「〜でいい」「〜だよね」 | 「〜すべき」「〜必須」「〜しないと損」 |
| 敬語 | 基本タメ口。商品説明パートだけ丁寧に | 定型ビジネス敬語 |
| 自己言及 | ブランド名を主語にしない。「あなたの夜」が主語 | 「ChenMeは〜を実現」 |

### 2.2 コピーの作法
1. **一文は短く。読点で切る。** 例：「靴、脱いだ。今日はここまで。」
2. **数字は「3分」「1プッシュ」「1日の終わり」だけ**。効果の数字（%、cm、日数での変化）は使わない。
3. **英語は締めだけ、短く、小文字混じりの上品さ。** `Coming back soon` / `Stay tuned` / `See you soon` の3語系で統一。全大文字にしない。
4. **問いかけで始めてOK**：「今日、何時間立ってた？」
5. **命令しない**：「〜してください」→「〜していい日」

### 2.3 締め表現（統一）
在庫切れは**ポジティブな"待ち時間"**として扱う。**購入・購入導線の言葉は出さない。**

| 用途 | 使用表現（英語） | 添える日本語（任意） |
|---|---|---|
| 標準の締め | **Coming back soon** | もう少しだけ、待ってて |
| 期待感を強めに | **Stay tuned** | 次のお知らせ、逃さないで |
| やさしく余韻 | **See you soon** | また、夜に |
| 通知誘導（プロフィール等で） | **Get notified** | 再販のお知らせはこちら |

タイポ規定：Latin serif（§5）、字間 +5〜+8%、サイズはフレーム幅の 6〜8%、色は Charcoal または Rose、背景に薄い白のブロックは入れない（余白で見せる）。

## 3. 使う言葉・避ける言葉

### 3.1 使う言葉（Approved）
| カテゴリ | 語彙 |
|---|---|
| 気分・印象 | スッキリ（※印象として）、軽やかな気分、ふう、リセット、ととのう、ご褒美、おつかれ |
| 行為 | ほぐほぐ、なでる、包む、あたためる（手で）、1プッシュ、3分、ゆっくり |
| 質感・香り（**2026-09-08 解禁**） | うるおうのにべたつかない、なめらか、しっとり、**ホワイトシトロンの香り**、心がほぐれる香り。※温感／冷感は事実確認が取れていないので引き続き使わない |
| 成分（注記必須） | マグネシウム*配合（*塩化マグネシウム・整肌成分）、セラミド*・ユーグレナ*（*保湿成分）、7つの無添加*（*パラベン、合成着色料、動物性原料、サルフェート、石油系界面活性剤、紫外線散乱剤、紫外線吸収剤）。**注記は同一画面・可読サイズ（36px以上）で** |
| 時間・習慣 | 今日より明日、夜の3分、寝る前、1日の終わり、ルーティン、続けたくなる |
| 在庫 | もう少しだけ、待ってて、Coming back soon、Stay tuned、再販のお知らせ |

### 3.2 避ける言葉（Prohibited）— 薬機法・景表法・ブランド上の理由
| NG語 | 理由 | 言い換え |
|---|---|---|
| むくみ解消／むくみ改善／むくみが取れる | 化粧品では身体変化の標ぼう不可 | 「スッキリした印象へ」「軽やかな気分に」 |
| 血行促進／代謝アップ／リンパを流す／老廃物 | 医薬品的効能 | 「マッサージしながら」「手であたためて」 |
| 脚が細くなる／引き締め／脚痩せ／サイズダウン／セルライト | 身体変化・痩身 | 使わない（印象語に置換不可。**訴求自体をやめる**） |
| 疲労回復／だるさが治る／痛みが和らぐ | 医薬品的効能 | 「おつかれの脚をいたわる」「1日の終わりのご褒美」 |
| 筋肉の緊張が和らぐ／こわばり／コリ固まった／体がほぐされる／浸透してリラックス | 身体の構造・機能への作用（Amazon ページにあるが動画では不可） | 「心がほぐれる」「ふう、とゆるむ時間」 |
| 限界マグネシウム／高濃度／◯◯mg | 根拠説明が必要な強調・数値。競合と同じ土俵に乗る | 「マグネシウム*配合」＋注記 |
| 医師推奨／臨床／エビデンス／〇〇%が実感 | 根拠不明・優良誤認 | 使わない |
| 最安／No.1／唯一／史上最高 | 景表法（比較・最大級） | 使わない |
| 今だけ／残り◯個／急いで／売り切れ間近 | 煽り。在庫切れ中は特に虚偽リスク | 「Coming back soon」「Stay tuned」 |
| 買って／購入はこちら／カートへ | 在庫切れ期間は購入導線を出さない | 「Get notified」（通知） |
| 痩せ／ダイエット／ボディメイク | ブランド外。ターゲットの自己否定を煽る | 使わない |
| 女子力／モテ／彼に | 古い。ターゲットが引く | 使わない |

### 3.3 グレーゾーンの扱い
- **「ほぐす」**：商品名なのでOK。ただし「筋肉をほぐす」「コリをほぐす」など身体部位＋効果はNG。「ほぐほぐする（動作）」「ほぐほぐタイム（時間）」として使う。
- **「スッキリ」**：印象・気分の語として使う。「脚がスッキリ細く」はNG。「スッキリした気分で明日へ」はOK。
- **「マッサージの効果」を言う場合**：「マッサージしながら塗ると、気分もほぐれる」のように**手の動作が主語**、クリームの効果と読めない書き方にする。
- **使用感**：香り＝ホワイトシトロン、テクスチャ＝うるおうのにべたつかない、は Amazon 商品ページで確認済み（`02_research/product_facts.md`）。温感／冷感は未確認のため使わない。
- **Amazon ブランド動画（夜景×白×ラグジュアリー）とは混ぜない。** SNS 広告は本書のピンク×等身大で統一。
- 迷ったら `02_research/compliance_yakkiho.md` のチェックリストを通す。

## 4. カラーパレット
正式素材から実測した値（アンチエイリアスの平均のため ±10 程度の誤差あり）。**ラベル・ロゴの色はこの表で"再現"しない。必ず画像そのものを使う。** パレットは背景・テロップ・UIのため。

| 役割 | 名前 | HEX | 由来／用途 |
|---|---|---|---|
| Primary BG | **Blush Pink** | `#FDCBD7` | 商品写真の背景ピンク。動画の基調背景、単色カット |
| Secondary BG | **Petal** | `#FCDDE5` | グラデの明るい側。テロップ背景ブロックには使わない |
| Base | **Milk White** | `#FFF8F6` | 余白・ボトルの白に馴染む。白100%より0.5段暖かい |
| Text Main | **Charcoal** | `#6A6664` | ロゴのグレー。本文テロップの標準色 |
| Accent 1 | **Rose** | `#C12844` | KVコピーの深いローズレッド。**見出し1語だけ**に使う |
| Accent 2 | **Label Blue** | `#6E93C4` | 商品名の手書きブルー。動画内では**線・小アイコンのみ**、文字色には使わない |
| Accent 3 | **Orchid** | `#AF75A5` | 「ChenMe」文字の紫。ブランド名の近くの小要素のみ |
| Accent 4 | **Moon Gold** | `#D3B27A` | ラベルの月。キラ・星のSEに合わせた小さな光だけ |

### 実物との差（2026-09-08 実物写真で確認）
| 要素 | レンダー（01〜04） | 実物（05・06） | 制作上の扱い |
|---|---|---|---|
| イラストのピンク | 淡い（彩度 0.25） | **濃くて赤い**（`#C2657C`、彩度 0.48） | 実物が正。彩度を落とす補正禁止 |
| 「ChenMe」文字 | 紫 `#AF75A5` | 暖色光下でローズ `#C26B7F` | 紫に寄せる補正禁止。Orchid は UI 小要素のみに残す |
| 商品名の青 | 明るい青 `#6E93C4` | 青みグレー `#898A92` | Label Blue は動画内の線・アイコン用のまま。文字色には使わない |
| ラベル紙 | 純白 | わずかに温かい白 | Milk White `#FFF8F6` と相性が良い＝規定通り |
| ボトル | ツヤあり白 | **マットな白**、角丸、なだらかな肩 | 反射を作らない。ライトは横〜45°、ハイライトを飛ばさない |

### 配色ルール
- **面積比の目安：Blush/Petal 60% ／ Milk White 30% ／ 文字＋アクセント 10%**。ピンクを全面に敷くと安っぽくなる。白を必ず入れる。
- Rose は 1画面に **1要素だけ**。2つ以上で「セール感」が出る。
- 黒（#000）と純白（#FFF）は使わない。影は Charcoal 20% 以下。
- グラデーションは Blush→Petal の**同系のみ**。紫・青へのグラデは禁止。
- 肌色補正：ピンク背景に負けないよう、肌は少し明るめ・彩度控えめ（LUT設計は §6）。

### 5.2 テロップ規定 v2（9:16 / 1080×1920 基準）— 2026-09-08 改訂
> v1（細字・座布団なし・灰色）は「背景に溶けて安っぽい」と判定。伸びている美容系ショート広告の共通項（太字サンセリフ／高コントラスト／白い角丸の座布団／下 1/3／短いフレーズ／キーワードだけ色を変える）に合わせて改訂。
- **本文**：Noto Sans JP **Bold（700）** 64px、1行 最大 12 文字、最大 2 行。**Milk White 92% の角丸座布団**（角丸 = 文字サイズ×0.42、余白 横 0.55em／縦 0.32em）に Charcoal の文字。表示 1.5〜3.0 秒。
- **見出し**：Noto Sans JP **ExtraBold（800）** 92px、1 行、同じ座布団。
- **強調**：1 テロップにつき **1 語だけ Rose `#C12844`** に（例：夜の**3分**。／**べたつかない**）。2 語以上は禁止。
- **英語締め**：Cormorant Garamond Medium 100〜104px、字間 +8、**座布団なし**、Rose（暗い背景では Milk White）。
- **位置**：本文・見出しは **縦 62〜72%（Y 1200〜1380）**。被写体（顔・ボトル）に被る場合だけ上部 Y 300〜340 へ。上 220px・下 430px・右 120px は空ける。
- **アニメーション**：ポップイン（スケール 94→100%＋フェード、6 フレーム）、アウトはフェード 5 フレーム。バウンス・タイプライター・ネオン・虹色は禁止。
- **吹き出し（コメント返し）**：白 94%・角丸 40px・Blush の丸アイコン・Noto Sans JP Bold 54px。Y 380。

## 6. 映像トーン

### 6.1 画づくり
| 項目 | 規定 |
|---|---|
| 比率／解像度 | 9:16 / 1080×1920（TikTok・Reels 共通）。1:1・4:5 はフィード用に再構成 |
| フレームレート | 24fps（"映画感"）。ASMR カットのみ 60fps 撮影→24 配置でスローを許可 |
| 色温度 | 3200〜4000K の暖色。夜の部屋。青白い光NG |
| コントラスト | 低〜中。黒を締めすぎない（シャドウは Charcoal 寄り） |
| 肌 | ナチュラル。美肌フィルター強めNG。毛穴を消しすぎない（等身大） |
| 被写界深度 | 浅め（F1.8〜2.8 相当）。背景のランプはボケで丸く |
| カメラの動き | ゆっくり（push-in 3〜5%/秒、手持ちの微揺れは可）。急ズーム・ホイップパンNG |
| 商品の見せ方 | **ボトルは常に"置いてある"か"手に持たれている"。** 回転・浮遊・爆発・液体の演出でボトルを歪めない |

### 6.2 LUT／グレーディング方針（Premiere Lumetri 基準）
- Basic：温度 +5〜+10、色かぶり +3（マゼンタ側）、露光 ±0、ハイライト −10、シャドウ +8、白 −5、黒 +5
- Creative：フェード量 8〜12（フィルム感）、彩度 95、自然な彩度 +10
- Curves：Hue vs Sat で青系 −15（青白さを抜く）、肌色（オレンジ）の明度 +5
- ビネット：−0.5、中点 60（弱く）

### 6.3 音
| 要素 | 規定 |
|---|---|
| BGM | ローファイ／アコースティック／ピアノ。BPM 70〜95。歌モノNG（テロップと競合）。トレンド音源を使う場合は**歌なし版**か音量 −18dB 以下 |
| ASMR/SE | ポンプ音、クリームの「とろ」、手のなでる音、シーツの擦れ、ため息。**すべて実録**。フォーリーはやりすぎない |
| ナレーション | ささやき手前の小声。若い女性の声。「読み上げ」感NG。字幕は必ず併記 |
| ラウドネス | −16 LUFS（統合）、ピーク −1dBTP。BGM は声の −12dB 下 |

### 6.4 出演者の雰囲気
- **21〜24 歳に見える**（2026-09-08 改訂：初稿の 25〜27 見えは「若く」と FB）。**「モデル」より「近所の綺麗な先輩」**。
- メイクはナチュラル、髪は下ろす／ゆるいお団子。ネイルは短めのヌードかミルキーピンク。
- 服：サテンのキャミワンピ、ロンT×ショーパン、ルームウェア。**KV の女性（`03_keyvisual`）を基準**。
- 表情：目を閉じて「ふう」、そのあと小さく笑う。カメラを見て話しかけるのは1本につき1回まで。

## 7. 禁止事項（まとめ）

### ビジュアル
1. ボトル・ラベル・イラスト・ロゴの改変（変形／色変更／加工／再タイプ／トリミング欠落／アニメーション化）
2. 生成AIにボトル・ラベル・ロゴを描かせること（合成 or 実写のみ）
3. ボトルを浮かせる・回す・爆発させる・液体を派手に飛ばす演出
4. 蛍光灯・青白い光・白飛び・強いコントラスト・ネオン
5. ピンクの全面塗り（白の余白を必ず残す）
6. ビフォーアフターの**身体**比較（脚の太さ・むくみの見た目比較）。**表情・気分の変化のみ**可

### 言葉
7. 効能の断定（§3.2）、比較・最大級、医療・痩身ワード
8. 煽り・偽の希少性（「残り◯個」「今だけ」）。在庫切れは事実として"待ち"を演出する
9. 在庫切れ期間中の購入CTA（「購入はこちら」等）。通知導線のみ
10. 「女子力」「モテ」等の古い価値観、ターゲットを"子ども扱い"する語

### 運用
11. 他社製品・他ブランドの映り込み（韓国コスメの棚を撮る場合はラベルを外す／ぼかす）
12. 出演者の権利未確認素材、トレンド音源の商用利用規約未確認
13. 「なるね」等クリエイターの動画の無断転載・切り抜き
