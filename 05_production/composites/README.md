# composites — AI の手 × 実物ボトル切り抜き（現物なしで作った「実写代替」）
作り方：`gen_hands.py`（Gemini 画像、R4 の手を参照、**無地の白いプレースホルダーボトル**を持たせる）→ `composite_hands.py`（`assets/product/bottle_front_cutout_level.png` を**均等スケール**でプレースホルダーに重ね、肌マスクで指をラベルの前に戻す）。
ボトル本体は変形・色変更なし（露出ゲインのみ、0.85〜0.92）。
| ファイル | 台本 | 状態 | メモ |
|---|---|---|---|
| `C1_hold_front.jpg` | C#1・#2 | ◎ | 両手で側面と底を持つ。指がラベルの前に正しく戻っている |
| `B3_pump_press.jpg` | B#3・A#5 | ○ | 指がポンプ上、下に手。左下にプレースホルダーの欠片 → AE でクローン |
| `C4_place_table.jpg` | C#4 | ○ | 置いて手を離す。右上に小さな欠片 → クローン |
| `B7_tea_bottle_bg.jpg` | B#7 | ○ | ティーを持つ手、奥にボトル。本番はボトルにガウス 6px（被写界深度合わせ） |
| `B4_cream_palms.png` | B#4 | ◎ | ボトルなし、純 AI（クリームは手の甲に） |
bbox は `--bbox=x,y,w,h`（画像比率）で手指定。自動検出はテーブルや照明の白を拾うため信用しない。
動画化：まず静止画のまま Premiere で 2〜3% のスケール／位置キーフレーム（Ken Burns）。Veo で「手が微かに動く」を試す場合はラベル領域の SSIM ≥ 0.97 を条件にする。
