# ボトル配置ワークフロー — 改変ゼロで動画に置く方法
### 対象：3案すべて。原則「AIにボトルを描かせない」。
最終更新：2026-09-08

---

## 0a. 決定（2026-09-09）：「動いている間は無地、最後だけ本物」
> FB「静止画は微妙、最後の合成は違和感」を受けて方針転換。**動きのあるカットは AI が生成した"無地の白いボトル"で通し、最後の `Coming back soon` の静止した瞬間だけ、実物ラベルの切り抜きを無地ボトルの位置に合成して"浮かび上がらせる"。** ラベル・イラストは一切改変しない（実物画像をそのまま置くだけ）。無地→ラベルの変化が「戻ってくる」の演出になる。
- 無地ボトルは実物と同じ比率（全高:幅 ≈ 2.3、白マット、白いポンプ）で生成させる。
- 途中のカットでラベルが無いことは、ボトルを小さく／斜め／手で持たせることで意識させない。最後で正体が分かる構造。
- 実装：`c_v02_generate.py`（Veo 4 本）→ `assemble_roughcut.py C2`（最終フレームの無地ボトルを自動検出→切り抜き合成→0.8 秒クロスフェード）。

## 0. 結論（優先順位）
| 優先 | 方法 | 使う場面 | リスク |
|---|---|---|---|
| **1** | **実物ボトルを実写** | ボトルが映る全ショット（A#4,5,8,9／B#2,3,7,8,9／C ほぼ全部） | 最小。最も安く、最も綺麗 |
| 2 | **正式画像の切り抜きを合成**（AE/Premiere） | 実写できない・AI 生成の空間に置きたい | 中。ライト合わせと接地影が勝負 |
| 3 | **正式画像を開始フレームにした image-to-video**（カメラ動きのみ） | B#2 の"点灯"のような、静止した商品に光だけ変えたい時 | 中〜高。生成後の**フレーム差分検証が必須**。歪めば即 1 か 2 に戻す |
| ✗ | text-to-video でボトルを生成 | — | 禁止。ラベル・形状が必ず崩れる |

> 手元に実物があるなら **1 で全部撮れ**。スマホ（iPhone 15 以降のシネマティック/ProRes）＋ランプ 1 灯で足りる。AI は「人物・空間」担当、ボトルは「実写」担当、と役割を分ける。

## 1. 実写の撮り方（方法1）
- **固定**：ボトル底に両面テープ or 粘着ジェル。ポンプを押しても動かない。
- **ラベル正対**：カメラ光軸に対しラベル面を ±5° 以内。C#2 の"傾け"でも ±10° まで。
- **反射**：白いポンプ・ボトル面が光を拾って飛びやすい。ランプは真横〜45°、正面からは当てない。偏光フィルタがあれば使う。
- **露出**：ラベルの白を 85〜90% に（ヒストグラムで右端に付けない）。ボトルが主役のカットは −0.3EV。
- **ポンプ押し**：出演者の手は下から。押した後 0.5 秒は手を止める（ブレ防止）。
- **フォーマット**：4K 24fps（スロー用は 60fps）、Log or フラットプロファイル。同じ光で「ボトル単体の静止プレート」も 5 秒撮っておく（合成・サムネ用）。

## 2. 合成の手順（方法2）
### 2.1 切り抜き素材（作成済み：2026-09-08）
**`assets/product/bottle_front_cutout_level.png`（474×1056、透過、水平化済み）を標準で使う。** 元は実物写真 `06_real_bottle_front_wall.jpg`。
再生成手順（同じ結果を出すため）：
```bash
pip install rembg onnxruntime opencv-python-headless
python3 - <<'PY'
from rembg import remove, new_session; from PIL import Image
im=Image.open("assets/product/06_real_bottle_front_wall.jpg")
out=remove(im, session=new_session("isnet-general-use"), alpha_matting=True,
           alpha_matting_foreground_threshold=240, alpha_matting_background_threshold=20, alpha_matting_erode_size=8)
out.save("rembg_06.png")
PY
# → 最大連結成分だけ残す → 本体の左右エッジから傾きを測って回転（スケール 1.0）→ 余白をトリム
```
- **解像度の限界**：全高 1056px。1080×1920 のフレームで**ボトル全高がフレームの 50%（960px）以下**なら等倍以下で置ける。それ以上に寄るカット（ポンプのマクロ、ラベルのマクロ）は**実写**。
- **傾き**：写真そのままの `bottle_front_cutout.png` は約 1〜2° 右に傾いている（左右のエッジで 0.1°〜2.3°、軽い遠近あり。回転は平均の 1.2°）。手持ち風に見せたい時はこちら、置きカットは `_level` を使う。
- より高解像度の正式画像（印刷用ラベルデータ、メーカー撮影の PNG）が入手できたら、同じ手順で作り直して差し替える。

（旧手順：Photoshop で手動切り抜きする場合）
1. `06_real_bottle_front_wall.jpg` を使う（レンダー 02 は質感が実物と違うため合成には使わない）。
2. Photoshop：**選択とマスク** → 被写体を選択 → 境界を 1px 内側 → ぼかし 0.5px。ポンプの細い部分は手で補正。
3. **絶対に「ゆがみ」「遠近法」「自由変形の非等倍」を使わない**。書き出し：`bottle_front_cutout.png`（元解像度のまま、sRGB）。
4. 参考の"影"は入れない（影はシーン側で作る）。
5. `assets/product/` に保存し README の表に追記。

### 2.2 置く（After Effects 推奨。Premiere だけでも可）
| 手順 | AE | Premiere のみ |
|---|---|---|
| 位置合わせ | プレート（AI 生成 or 実写背景）にカットアウトを置き、**スケールは縦横比ロック**。位置と回転（±15°まで）だけ | 同じ。「均等スケール」ON |
| カメラ動き追従 | プレートに動きがあれば **3D カメラトラッカー**（または Mocha 平面トラック）で床面にアタッチ | プレートは「静止」または push-in のみに限定し、同じキーフレームを手で付ける |
| 接地影 | カットアウトを複製→黒（Charcoal）に塗り→Y 反転・潰し（**影レイヤーのみ**変形可）→ ブラー 20〜40px、不透明度 25〜35%。ボトル本体は触らない | 同じ（クロップ＋ブラー＋不透明度） |
| ライト合わせ | **許可**：露出（レベル）、全体のガンマ、わずかなカラーバランス（±5）。**禁止**：色相回転、彩度の大幅変更、ラベル部分の個別補正。ラベル領域はマスクで**保護**し、補正は保護外にのみ | Lumetri「基本補正」の露光・コントラストのみ |
| なじませ | 「ライトラップ」：プレートをぼかし 40px → カットアウトの内側 6px にスクリーンで 15% | 省略可 |
| 検証 | 100% 拡大で①ラベル文字の縦横比②ポンプの直線③枠線の直線 を目視。元画像と並べて確認 | 同じ |

### 2.3 AI プレート側の作り方
- 生成時のプロンプトに **「a plain matte white rounded-rectangle pump bottle without any label as a placeholder, about 2.3 times taller than wide, pump head roughly the top 30% of its height」** を入れて位置と影を取る（実物の比率：全高:幅 ≈ 2.26、本体 ≈ 1.58、ポンプ ≈ 全高の 30%）。生成後、そのプレースホルダーの上にカットアウトを重ねる（プレースホルダーは隠れる）。
- 大きさが合わない場合は**プレートを**スケールする。ボトルは等倍のまま。
- 手がボトルを持つショット（C#1,2）は合成しない。**実写のみ**（指とボトルの前後関係が破綻する）。

## 3. image-to-video（方法3）の条件
- 開始フレーム：**正式画像そのまま**（トリミングは 9:16 に合わせる範囲で、ボトルの一部を切らない）。
- プロンプトは「光の変化」「ごく小さなカメラ push-in（≤3%）」のみ。物体の動き・手の追加・液体を頼まない。
- 尺は 2 秒以内。長いほど崩れる。
- ツール：Kling 3.0 / Runway Gen-4 の image-to-video、Veo 3.1 の first-frame。3 ツールで各 4 本、計 12 本生成して最良を選ぶ（打数）。

## 4. 検証手順（方法2・3 共通、必須）
```bash
# ffmpeg と ImageMagick がある環境で。生成クリップの先頭と末尾フレームを抜き、ボトル領域を元画像と比較
ffmpeg -i clip.mp4 -vf "select=eq(n\,0)" -vframes 1 f0.png
ffmpeg -i clip.mp4 -sseof -0.05 -vframes 1 fN.png
# ボトル領域（例：x=380 y=900 w=320 h=760）を切り出し
magick f0.png -crop 320x760+380+900 b0.png
magick fN.png -crop 320x760+380+900 bN.png
magick compare -metric SSIM b0.png bN.png diff.png
```
- **SSIM ≥ 0.97** なら合格（光の変化だけ）。それ未満はラベルが動いている＝**不採用**。
- 目視チェック 5 点：①「ほぐほぐクリーム」の文字が読める ②イラストの脚のラインが崩れていない ③「ChenMe」の serif が保たれている ④枠線が直線 ⑤ポンプが曲がっていない。
- 結果は `06_qa/quality_review_log.md` に記録（クリップ名、ツール、SSIM、可否）。

## 5. やってはいけないことリスト（再掲）
- text-to-video でボトルやラベルを生成
- 非等倍スケール、ワープ、パペット、遠近法変形（影レイヤー以外）
- ラベル領域の色補正、彩度・色相の変更
- ラベルのイラストや文字をアニメーション化（ラベルの子が"動く"演出は不可）
- 別フォントで「ChenMe」「ほぐほぐクリーム」を打ち直す
- ボトルを浮かせる・回す・液体を派手に飛ばす
